# Interest Rates Blogger Template

This repository contains the extracted Blogger XML theme from the saved Blogger template editor page.

## Change made
- Replaced `http://1nterestrates.blogspot.com` / `https://1nterestrates.blogspot.com` with `https://interestrates2.com`.

## Install in Blogger
1. Open Blogger and select the correct blog.
2. Go to Theme.
3. Back up the current theme before changing it.
4. Use **Edit HTML and replace the template with the contents of `interest-rates-blogger-template.xml`, or use the theme restore/upload option if available.
5. Preview and test the blog before publishing.

The XML is the Blogger theme code extracted from the saved webpage; it is not the full saved webpage itself.
